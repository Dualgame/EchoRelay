Nothing in this repository adds a license, to upstream code or to the files it adds (`EchoRelay.Headless/`, `docs/`,

## Purpose

This repository is for **research and educational purposes**: studying Echo VR's service protocol and the client
features its final builds shipped but never had services for. It is meant for personal research on a LAN. It is not
a public matchmaking service, and the upstream disclaimer applies unchanged: upstream does not condone publicly
hosting matches with this solution.
